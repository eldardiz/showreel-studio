# SFX library (user-supplied)

Nothing is bundled. Drop files here and reference them from a manifest's `audio.sfx.library`:

| key | suggested file | used by |
|---|---|---|
| whoosh-soft | whoosh-soft.wav | blurReveal, zoomEnter |
| whoosh-hard | whoosh-hard.wav | whip |
| click | click.wav | flash, hard cuts (optional) |
| riser | riser.wav | before the end card (optional) |

Keys are free-form; the manifest maps key → file. Use WAV or MP3 at 44.1 kHz.
